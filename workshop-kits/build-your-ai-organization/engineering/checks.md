# Evaluation checks

Normal case: Bounded diff, acceptance evidence, browser observation or explicit blocker, and review notes.

Edge cases: Filter with zero matches; use an unknown status; refresh the view; run with missing fixture file. Confirm the empty state and error are distinct. A tool unavailable for browser checks must be recorded as an unverified check.

Log: case ID | input version | expected behavior | observed output | evidence | reviewer | pass/fail/unverified.
